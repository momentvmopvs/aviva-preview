# a.viva — Prévia do site

Repositório público de demonstração do site multipáginas a.viva — Eventos & Marketing Promocional.

## Publicação

1. Descompacte o pacote `aviva-site-multipaginas-atualizado.zip`.
2. Entre na pasta `aviva-site-multipaginas` e envie **seu conteúdo** para a raiz deste repositório, incluindo `index.html`, as demais páginas HTML, `styles.css`, `script.js` e a pasta `assets/`.
3. Em **Settings > Pages**, selecione **Build and deployment > Source: GitHub Actions**.
4. Em **Actions**, confirme a execução do fluxo de publicação.
5. Prévia esperada: https://momentvmopvs.github.io/aviva-preview/

Atenção: a prévia é pública. Revise imagens e informações de contato antes de compartilhar.
